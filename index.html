契约与后期迁移说明（点开）

当前范围：JavaScript / TypeScript / HTML / CSS 四门浏览器原生，加上第一门 WASM 语言 Lua 5.4。JS/TS 默认走 Worker（worker.terminate() 能真杀无限循环），HTML/CSS 走 sandbox="allow-scripts" 的 iframe，TypeScript 用官方 transpileModule 动态加载转译。

Lua 实现：wasmoon 1.16.0 跑在独立 module Worker 里，glue.wasm 用 Vite ?url 自托管（默认会去 unpkg，内网/离线不可用，已显式覆盖为同源地址）。Worker 先初始化引擎发 ready，主线程收到后才起墙钟计时 —— wasm 下载与实例化不算进用户代码预算；同步死循环靠 worker.terminate() 真杀。Lua 侧薄壳把 print/io.write 接到输出通道（绕开 Emscripten 行缓冲，无换行也不丢）、io.read 读契约注入的 stdin、os.exit 改成可读错误；第二个 .lua 文件挂到内存 FS，可用 dofile('/helper.lua') 加载。traceAllocations: true 让内存用量与上限都可计数，probes 里能读到 Lua 版本、wasm URL、实际内存用量。

契约先行：RunRequest 已含 target: browser | server、limits（wall/cpu/memory/output）、files[]、stdin；RunResult 已含 exitCode: number | null（浏览器没有退出码，不假装 0）、usage、probes、preview。能力表 Capability 由注册表 active() 推导 —— 没接线就置灰，单测骗不过去。加一门语言只要登记 + 实现 Runner + 注册 + 加示例 + 补端到端判据，UI 一行不改。

迁移到服务端：src/runners/server/piston.ts 已实现 Runner 接口、buildPistonBody()（显式传内存限额，不吃 Piston 默认的 -1）与 mapPistonResponse()（RE/SG/TO/OL/EL/XX 六种状态映射），默认 enabled: false 且不注册。启用只需在 createRegistry() 传 ServerWiring，能力表会自动出现 server 位置与「可判分」。

已知边界：iframe 内同步死循环会冻结标签页（浏览器限制），该模式的超时判据不做自动验证；JS/TS 请用 Worker 载体。首版不支持模块 import/export。预览 iframe 是 opaque origin，event.origin === 'null' 证明不了任何事，代码里靠 event.source + requestId 双重校验。Lua 没有真实网络与文件 IO，每次运行新建引擎（变量不跨运行），没有 REPL session。wasmoon 是 UMD 包，构建时 Vite 会 externalize 它引用但浏览器下并不使用的 node 内建模块，属于预期警告，dev 与 dist 两层真机都已验证。

验收：npm run verify（类型检查 + 40 条单测 + 构建）；npm run smoke 用本机 Chromium + CDP 打开 ?selftest=1 跑真浏览器端到端判据（39 条：37 绿 / 2 条按白名单记账跳过）；npm run smoke:preview 在 dist 产物里跑同一套判据（验证 build 后的 wasm 路径）。四个拆线负例：npm run negative（摘 CSS）、npm run negative:lua（摘 Lua）各精确红 1 条；npm run smoke:negative（掐 iframe 回传）精确红 10 条；npm run smoke:negative:lua（掐 Lua stdout 回传）精确红 8 条并核对红的 id 集合 —— 两层负例都证明判据不是「怎么改都全绿」。

体积基线（1024 口径，gzip 实测）：与上一版 bcca147 用同一脚本真实对照 —— 首屏 JS 9.74 → 10.85 KB，CSS 恒 1.58 KB，首屏合计 11.32 → 12.43 KB（+1.11 KB）。Lua 相关全部懒加载：切到 Lua 编辑器 +1.39 KB；首次运行再下 lua-worker 36.45 KB + glue.wasm 108.04 KB = 144.49 KB gzip，不运行 Lua 的用户一个字节都不下载。后续每加一门语言继续按这个口径先量再合并。
